Where to find the numbers

Start with the station manual

Watt-hours (Wh) describe stored energy. Watts (W) describe how much power the station can supply at once. Look up both the continuous AC output and its surge rating and duration. Also check the limits of each outlet you plan to use.

Measure what each device uses

Use the device manual or an appropriately rated plug-in watt meter. Charger draw can taper as a phone fills. For devices that cycle, such as refrigerators, a full day’s measured Wh is more useful than assuming they run nonstop. For this planner, divide measured daily Wh by running watts to enter equivalent daily run time. Look up startup watts separately.

Decide what to run first

Prioritize lighting and communication. Run flexible loads at different times if the combined watts exceed the rating. Compare each device’s startup draw and required surge duration with the station manual before connecting it.

Plan medical backup with the equipment provider. Confirm the approved backup source, expected duration, and what to do if power cannot be restored. FDA outage guidance for medical devices.
