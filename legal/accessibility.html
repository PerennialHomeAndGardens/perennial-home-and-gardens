Accessibility Statement

Perennial Home & Gardens aims to make its website useful across common devices and accessible to visitors using assistive technology.

We are working toward clear navigation, readable contrast, keyboard-friendly controls, meaningful link text, image alternatives and responsive layouts.

If you experience difficulty using a page, form, resource or feature, contact Perennial through the website and describe the problem so an alternative can be provided when reasonably possible.
